# My-Niri-Dotfiles
Here's my Niri dotfiles, now with Noctalia!

### Installation
These packages require manual install or yay if you're using Arch or Arch-based distros. If you are okay with it, use the `install.sh` script to install packages and dotfiles for you. This requires a password prompt, so safety first.

```
cd My-Mango-Dotfiles
./install.sh
```
